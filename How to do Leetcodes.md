# How to do Leetcodes



### The problem-solving cycle : (9/4115)



##### A. Understand the problem



1. Read the complete problem statement.
2. Identify inputs, outputs and constraints.
3. Understand the examples.
4. Think about edge cases.



##### B. Identify knowledge gaps



1. Identify the relevant topic (arrays, binary search, DP, graphs, etc.).
2. Learn only the concepts necessary to make progress.
3. Avoid watching entire tutorials unnecessarily.



##### C. Think independently



1. Start with a brute-force solution.
2. Analyze its time and space complexity.
3. Look for optimization opportunities.
4. Select appropriate algorithms and data structures.
5. Write pseudocode before implementation.



##### D. Implement



1. Write code in VS Code or your preferred IDE.
2. Keep the implementation clean and readable.
3. Avoid copying solutions.



##### E. Test and analyze



1. Test normal cases.
2. Test edge cases and boundary conditions.
3. Check time and space complexity.
4. Use custom test cases and debug failures.



##### F. Submit



1. Submit on LeetCode.
2. Verify acceptance.
3. Understand why the solution passes.



##### G. Document



1. Commit the solution to GitHub.
2. Include the problem link and difficulty.
3. Explain the approach, algorithm and complexity.
4. Record mistakes and important observations.



##### H. Review and retain



1. Re-solve after 7 days.
2. Re-solve after 30 days.
3. Try without looking at your previous code.
4. Track whether you can independently derive the solution.
