### DSA Journey Map



#### University Unit 1



##### Stage 0 — Programming foundations



Start here,

Before solving DSA problems, make sure you understand:



1. Variables, data types, loops, conditions, functions and arrays.
2. Pointers, references and memory basics.
3. Recursion fundamentals and function calls.
4. Classes, objects and basic OOP concepts.
5. Time complexity and space complexity (Big O).
6. Python DSA data structures: list, str, tuple, dict, set, stack, deque, heapq, and sorting (sort() / sorted()).
